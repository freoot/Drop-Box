# 听见 · 每日内容助手

双击 **启动听见.command**，或运行 `python3 app.py --open`，打开 http://127.0.0.1:8768 。无需安装第三方依赖；需要 Python 3.9+ 和已登录的 Codex CLI。

点击“开始今日整理”，真实调用本机 Codex 进行公开网页搜索和阅读。默认关注中文泛知识、社会话题、商业和科技，近 3 天最多 8 条。页面包含每日精选、观点时间线、公众号选题、来源缺口、历史日报、Markdown 导出和偏好设置。也可以导入 SRT/VTT 字幕，按原始时间整理指定节目。

## 每日运行与 Codex

`python3 app.py --once` 会执行一次完整任务。通过 Codex 的每日自动化运行此命令，即使网页关闭也可生成报告。电脑和 Codex 需可运行；本工具不是云端常驻服务。定时任务在 Codex 自动化中修改/暂停。

使用 `codex --search -a never exec --ephemeral -s read-only --output-schema …`，沿用已有登录与模型设置，不另索取 API key。研究在临时目录执行，网页不直接持有账号令牌。界面按钮每次会使用你的 Codex 用量。完成后的 JSON 需通过字段、链接及时间依据校验才会归档。

报告保存在 `data/reports/`，运行状态在 `data/status.json`，故障详情在 `data/last-run.log`。状态、设置和报告采用原子写入，文件锁防止手动与自动任务重叠。日志只保存在本机，可能含研究过程，不应直接公开。

## 能力边界

- 小宇宙、X、微博、YouTube 通过公开搜索和网页阅读接入，未连接它们的登录 API，不保证每个平台每天都可读。
- 没有完整字幕或音频，不假装已经听完整期。章节与字幕依据分别标记；无依据不显示虚构时间。
- 目前不内置音频下载和自动语音转写；可以导入已有字幕。YouTube 时间链接支持跳转，其他平台展示回听位置与原始链接。
- 热度仅采用可见指标；未核验就明示。讨论情绪仅是实际读取的样本，不推断总体民意。
- 公众号功能提供选题及核验清单，不连接公众号发布账号。
- JSON 校验保证格式与证据字段齐全，不等于已经独立验证模型引用的每一项事实。
- 网络失败会显示失败或空报告及来源缺口，不填充假新闻。

## 测试

`python3 -m unittest discover -s tests -v`

测试隔离数据目录，包含 HTTP、报告校验、时间依据、字幕、导出、配置、并发锁、Codex 参数和失败恢复。真实联网运行结果单独记录于 `docs/verification.md`。
