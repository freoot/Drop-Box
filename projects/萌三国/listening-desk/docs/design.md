# 听见：第一版范围

用户明确授权制作桌面应用或桌面 HTML，自动发现热门播客与讨论，每日总结，接入现有 Codex。已确认主题：中文泛知识、社会话题、商业、科技，支持公众号选题。

实现选择：本地 HTML + Python 标准库服务 + 已登录的 Codex CLI。相比静态 HTML，能在本地触发真实 Agent 并持久化日报；相比原生桌面壳，无需额外安装依赖。服务只监听 127.0.0.1。当前不制作原生安装包。

每日由 Codex heartbeat 调度（北京时间 09:00），避免浏览器关闭后定时器失效。电脑和 Codex 的可运行状态仍是本地自动化的前提。

研究流程：读取偏好 → 搜索指定平台及公开 RSS/媒体 → 核验日期与热度证据 → 阅读可访问原文、字幕或章节 → 生成带证据的要点及总结 → 输出讨论样本和公众号选题 → 校验并归档。允许返回不足 8 条，禁止补造内容。

第一版的平台接入是 Codex 的公开网页搜索与阅读，不是各平台登录接口或全量抓取。无法读取的内容必须报告缺口。无字幕的完整音频自动转写不在此版本中；用户可以导入 VTT/SRT 字幕补充指定节目的精准整理。引用时间来自字幕或章节，不由模型估计。

验收：任务互斥与失败可见；配置持久化；报告与来源可追溯；时间证据不足时明确显示；中文导出；真实 HTTP 接口测试、恶意链接及跨站写入防护；Codex 实际运行验证单独记录，无法联网不能算通过。
