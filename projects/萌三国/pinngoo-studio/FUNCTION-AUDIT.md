## 接口依据与兼容性

- 参考图使用 [OpenAI Images Edit JSON 接口](https://developers.openai.com/api/reference/resources/images/methods/edit)，请求包含 `images[].image_url` 与图片数据。兼容平台必须支持这个接口格式，单纯支持文字生图并不足够。
- 首帧视频按 [火山方舟创建视频任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)，使用 `image_url` + `first_frame` 及图片 Base64 数据。实际图片像素、模型权限与额度仍由服务商验证。
- 真实图片密钥仍为空；本轮未生成真实图片或真实视频。33 项自动化采用隔离测试服务，未消耗真实图片/视频额度。
