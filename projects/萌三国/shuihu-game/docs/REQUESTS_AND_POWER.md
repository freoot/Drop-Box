# 角色、武力值与后续组合设计（2026-10-15）

## 本轮代码
- 人物详情、将册、招募结果：绰号在前，姓名在后。
- 招募小传直接显示，桌面与人物并列、手机上下排列。新增矮脚虎王英小传；没有独立长篇小传的角色显示已有简介。
- 武力值为展示指标，不参与伤害运算、不代表胜率：
  `round(生命×2 + 攻击×12 + 移动×80 + 射程×100 + (技能等级−1)×60)`。
  已拥有角色采用当前成长属性与已装备加成；未拥有角色为一级基础值。队伍武力值为上阵成员之和。权重集中于 hero-power.js，后续可调。
- 擂台展示我方各英雄等级、职业、武力值与阵容总值。截图中的玩家对手卡不等同单英雄，原型仍为本地模拟竞技场，没有伪造在线玩家排名。
- 酒馆接入已有三位休闲造型和程序关节动画、轮流短走/歇坐、原创聊天。掌柜缩小并保持柜台前景遮挡。并非完整三维骨骼、全方向走路和表情动画，眨眼仍待本地模型支持。

## 已确认、后续设计（本轮未重做）
- 蓝、紫、红、暗金四档；生命、攻击、移动、射程四属性。
- 战士克射手、射手克谋士、谋士克战士。
- 一项被动、两项主动二选一；高品质专属特性。
- 两人和三人组合可涵盖男女角色。按水浒人物关系与职业互补原创设计，组合效果应说明范围、倍率、回合、触发与冷却。性别本身不作为加成依据。
- 候选组合：王英＋扈三娘（近战保护与追击）；孙新＋顾大嫂（策应与解围）；张青＋孙二娘＋武松（二龙山接应）。这些是改编设计方向，尚未新增技能或改数值。
- 招募参考方向：普通免费/招贤符、高级免费/游戏币、十连至少一暗金；概率、保底规则必须可见。不接真实支付。
- 职业装备路线、关卡图纸、强化与进阶；试练塔铜币修为及阶段礼包；竞技场连胜积分、荣誉和兑换商店。以后改动需同时更新设计与实现，不把参考表当作已经实现。
- 王英剑谱留后续其他软件制作。
