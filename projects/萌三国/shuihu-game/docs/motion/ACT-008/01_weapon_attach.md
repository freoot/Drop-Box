# ACT-008 · hero005 现有武器 mesh 的真实挂接

## 1. 先查：武器到底在哪

打开 `r8/source/hero005.blend` 检查，结论和预期不同：

| 检查项 | 结果 |
|---|---|
| 场景对象 | 只有 `hero005_rig`（骨架）、`hero005_costume_and_body`（网格 14409 顶点）、`Icosphere`（42 顶点遗留杂物） |
| 独立武器对象 | **没有** |
| 顶点组 | 10 个：`root body arm.L hand.L arm.R hand.R head leg.L foot.L leg.R foot.R` —— **没有 `weapon.R`** |
| 材质槽 | 11 个，含 `silver.001` / `brown.001` / `gold.001` 等 |

也就是说：**截图里那把长柄武器，是并进角色网格、蒙皮在 `hand.R` 上的**。
`hand.R` 覆盖 1358 个顶点，其中既有手，也有武器。

用连通分量分析把武器分离出来：

| 分量 | 顶点数 | 主导权重 | 到 hand.R 骨距离 | 判定 |
|---|---|---|---|---|
| 大分量 ×2 | 225 + 225 | 100% `hand.R` | 0.93 / 1.13–1.66 | 武器主体（枪头 + 枪杆） |
| 小环 ×8 | 12 × 8 = 96 | 100% `hand.R` | 0.26–1.09 | 枪杆上的环饰 |
| 零碎 ×48 | 4–6 | 100% `hand.R` | 0.69–1.04 | 枪头/枪缨细节 |
| 手部 | 271 | 100% `hand.R` | **0.011–0.105** | 手（不分离） |

判据：连通分量整体 100% 由 `hand.R` 驱动，且到 `hand.R` 骨的距离 > 0.25（手部最远只到 0.105）。
共识别 **756 个顶点 / 60 个连通分量**。

## 2. 挂接：只搬现有几何，不新建

`tools/motion/attach_weapon.py`：

1. 复制角色对象 → 用 bmesh 只保留武器顶点（756 个），命名 `hero005_weapon`
2. 角色网格删掉这 756 个顶点（14409 → 13653）
3. 清空武器对象的顶点组，新建 `weapon.R` 并全部顶点权重 **1.0**
4. Armature 修改器指向 `hero005_rig`，父级设为骨架
5. 保存 `r9/source/hero005.blend` + 导出 `r9/models/hero005.glb`（**r8 原样保留**）

**新增几何：0 个顶点**。视觉一致性实测：分离前后武器 756 个顶点的世界坐标最大偏差
**6e-8**（浮点误差级）。

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/motion/attach_weapon.py
# → 退出码 0；角色 14409→13653，武器 756，偏差 0.00000006
```

## 3. 逐帧验证：不脱手、不穿地

`tools/motion/verify_weapon_frames.py` 对 **attack（0→1000ms，25 帧）** 与
**death（0→1600ms，40 帧）** 的每一帧采样：

- **不脱手**：把武器顶点变换到 `weapon.R` 局部空间，与第 0 帧逐点比对
- **不穿地**：武器与角色本体的世界包围盒最低点

首轮结果（修正前）：

| clip | 脱手偏差 | 武器最低点 | 身体最低点 | 判定 |
|---|---|---|---|---|
| attack | 7.2e-7 | **−0.0235** | −0.0000 | FAIL（武器穿地） |
| death | 6.2e-7 | **−0.1473** | **−0.0705** | FAIL（都穿地） |

脱手偏差在 1e-6 量级，说明挂接本身没问题；穿地是真问题：

- attack 的 −0.02 在**第 0ms 就存在**：武器长杆末端在静止姿态本来就探到地面以下 2cm
- death 在 41.7–541.7ms 身体与武器一起沉下去：倒地是绕脚底旋转，中段躯干必然扫过地面
  （此前只验末帧，所以没暴露）

## 4. 修正：为什么不能靠旋转，只能平移

先试过绕 `weapon.R` 骨旋转：2° 只抬 0.0001，15° 也只抬 0.0016 —— 因为武器最低点几乎就在
骨 head 的**正下方**，绕该点旋转时它沿圆弧横摆，高度只按 `1−cosθ` 变化（二阶小量）。

也试过平移 rest 骨：**完全无效**。蒙皮结果是 `M_pose × M_rest⁻¹`，rest 与 pose 同步平移后
乘积仍是单位阵。

最终做法（`tools/motion/fix_ground_penetration.py`）：

1. **全局**：武器网格顶点沿世界 Z 平移 **+0.026**（角色高 1.8 单位，约 1.4%），
   解决 attack 全段；手部网格不动
2. **death**：逐帧测「身体 + 武器」最低点，用 `root` 骨做贴地补偿（逐帧插 location 关键帧，
   余量 2mm），共抬升 9 帧

修正后：

| clip | 脱手偏差 | 武器最低点 | 身体最低点 | 判定 |
|---|---|---|---|---|
| attack | 7.2e-7 | **+0.0025** | −0.0000 | PASS |
| death | 7.3e-7 | **+0.0020** | **+0.0020** | PASS |

```
WEAPON_FRAMES_OK: 逐帧不脱手、不穿地（attack, death）
```
