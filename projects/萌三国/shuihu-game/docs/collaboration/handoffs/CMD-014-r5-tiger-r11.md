## 一、虎模型：从方块占位 → 真实资产

之前战斗里的虎是 Godot 侧用 11 个方块拼的占位物（远景就是一只方块箱子），
虎影也是程序化半透明方块。本轮做**真实虎资产**。

| 项 | 内容 |
|---|---|
| 源工程 | `assets/releases/ART-002/r11/source/tiger.blend`（226 KB，可编辑） |
| 模型 | `assets/releases/ART-002/r11/models/tiger.glb`（523,816 B） |
| 骨架 | 12 骨（含 tail） |
| 分件 | 57 个 mesh，各自顶点组绑骨 |
| 动作 | `idle` / `walk` / **`pounce`** / `hit` |
| 造型 | 原创分件几何（Blender ball/rod/box/curve），**非下载素材** |

### 可辨识特征

- **王字额纹**（三横一竖）、宽额虎头、圆耳（带内耳）、琥珀虎眼 + 深色瞳孔
- 白吻、白胸、白爪
- **环尾**（4 段贝塞尔 + 4 个深色环——虎尾有环纹，是与狮尾的关键区别）
- 躯干条纹 10 条 + 颈部条纹 6 条

第一版骨架太低（躯干中心 0.52），渲染出来像爬行的猫，已抬高到躯干 0.66、
头 0.98、爪 0.10，总高约 1.35 单位。

## 二、虎影：同一只虎

不再另做一个方块虎影——**直接用 r11 同一只虎**，覆盖为半透明金色材质：

```
加载 r11 → _apply_material() 覆盖所有 mesh 的 material_override
        → 半透明金 (1.0, 0.82, 0.35, 0.55) + UNSHADED + 双面
        → 播 pounce（蓄力→腾空→落地）
        → 扑向目标 → 撞上后爆开消散
```

它象征威势，**不跟随、不留在场上**（扑完即 `queue_free`）。

## 三、机位与朝向：量化标定，不再肉眼试

上一版「拳击远景不清晰」和「虎背对镜头」反复靠看图猜角度，效率低还反复错。
本轮写量化标定脚本，播放 `punch`、采样 `hand.R` 世界位移、投影到屏幕，算两个指标：

- **横向占比** = |位移.x| / |位移.xz| —— 拳在画面里是「横着走」还是「朝镜头变大」
- **脸朝镜头** = 模型正面（局部 +Z）的世界 z 分量 —— 越大越看得见脸

| rot.y | 横向占比 | 脸朝镜头 | 结论 |
|---|---|---|---|
| 30° | 0.03 | 0.87 | 拳朝镜头，看不出「挥」 |
| **60°** | **0.52** | **0.50** | ✅ **取这个** |
| 90° | 0.88 | −0.00 | 正对敌人，拳被身体挡 |
| 135° | 0.96 | −0.71 | 拳最清楚但完全背对 |
| −45° | 0.96 | 0.71 | 横向清楚但**方向朝左**（打错方向） |

**最终：武松 `rotation.y = 60°`，虎 `−60°`（对称）。**

> Godot 绕 Y **正向旋转是顺时针**，符号极易搞反——这是本轮反复踩的坑，
> 所以用量化脚本定值而非肉眼试。

镜头同时从 `(0.15, 1.95, 5.9)` 调到 `(-0.55, 1.38, 4.3)`，fov 50°。
