## 二、实现了什么

新增场景 `godot/tiger_tutorial/tiger_tutorial.tscn`（脚本 700 行），五步闭环：

```
① 教学战：武松 vs 虎（固定站位回合制）
      ↓ 胜利（必得，不随机）
② 招募：短对话，武松入队（只发一次）
      ↓
③ 编队：把武松放进出战位（写存档）
      ↓
④ 第二战：携带武松出战（敌人更强：120 血 / 16 伤害）
      ↓
⑤ 重启后仍持有武松与编队
```

### 战斗规则

| 项 | 值 |
|---|---|
| 站位 | 固定，我方左、敌方右，**不走格子、无移动** |
| 回合 | 我方 → 敌方 → 我方 |
| 操作 | 点敌人选中目标 + 点技能 |
| 普攻 | 18 伤害，**+25 怒气** |
| 虎影重击 | 35 伤害，**消耗 50 怒气**；武松出拳 → 猛虎虚影扑向目标 → 消散 |
| 防重入 | 行动结算中 `busy=true`，按钮禁用，连点无效 |
| 胜负 | 敌方归零→胜利；我方归零→失败→可重试 |

### 虎影的表现

半透明金色虎形从武松身前浮出，0.28s 扑到目标并放大，随后炸开消散。
它是**威势象征**，不跟随、不参与回合，不是宠物。

## 六、已知限制

1. **虎影/虎/拳击都是占位**：虎是程序化方块拼的，虎影是半透明几何，武松出的是双刀不是拳。
   要达到「武松亲自出拳、猛虎虚影扑出」的观感，需动作工作包出真资产。
2. 剧情文案是我按最小版本写的（教学 4 句、招募 2 句），不是剧情工作包的成品。
3. 第二战敌人复用同一个占位虎，只改了数值。
4. 存档是本地 JSON，无加密无云同步；没有多角色编队 UI，只有一个出战位。
5. 没有音效、没有 BGM、没有数值平衡。
