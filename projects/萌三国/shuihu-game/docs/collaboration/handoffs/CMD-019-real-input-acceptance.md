## 二、已完成且已验证的非交互部分

### 2.1 隔离试玩入口（新增 `tools/launch-tiger-prototype-isolated.sh`）

- 用**独立 HOME** 启动带窗口的打虎首关：`user://` 重定向进 `mktemp` 临时沙盒，
  主工程正式存档（`~/Library/Application Support/Godot/app_userdata/是好汉就上山/save.json`）**不可达**；
- 屏幕打印逐步操作与预期（人工验收单精简版）；
- 用法：`--keep-home`（复用最近一次沙盒）/ `--home <dir>`（显式指定，杜绝串到别次）/
  `--resolve-home`（只打印将用的沙盒并退出，供回归断言），可组合。

#### r2 返修（PM 源码复核发现，已修）

**缺陷**：旧版先 `mktemp -d` 新建目录、再 `ls -dt` 选"最新"目录 →
必然选中**本次刚建的空目录**，`--keep-home` 实际永远复用不到上次存档；
`PROBE_LOG` / `USER_DATA_DIR` 也在选择前绑定。

**修复**：先解析全部参数 → 按优先级确定沙盒
（`--home` 显式 > `--keep-home` 复用带标记的最近沙盒 > 新建）→ 之后才创建/绑定路径；
沙盒带标记文件 `.tiger-manual-sandbox`，`ls -dt` 只认带标记目录（避免串到无关临时目录）；
新增 `--resolve-home` 便于回归断言。

**回归证明**（`tools/verify-isolated-launch-reuse.sh`，证据落
`docs/evidence/CMD-019/isolated-launch-reuse-20261030-035151.log`，**8 项全过**）：

| # | 断言 | 结果 |
|---|---|---|
| B | `--keep-home` 复用上一次沙盒（未新建） | ok |
| C | `--home` 显式指定两次一致 | ok |
| D | 不带参数新建**独立**沙盒（≠ 上次） | ok |
| E3 | 第二轮 `--keep-home` 仍指向同一沙盒 | ok |
| E5 | 第一轮存档复用后**仍存在且 sha256 不变**（`580714d9…7402`） | ok |
| E6 | 新会话**另存新档**（sessions 由 1 → 2） | ok |
| F | 新沙盒**无任何存档**（与旧沙盒隔离、不串档） | ok |
| G | 主工程正式档 sha256 前后一致（`576bd249…99bf1`） | ok |

（E 段用 headless 演示跑两轮 **产出真实存档文件**以证明"复用后旧档仍在、新档另存"，
仅作目录/存档行为回归，**不替代人工真实鼠标验收**。）

已实测（非交互部分）：隔离 HOME 启动 Godot 4.7.2 窗口成功——
`display_server=macOS`、窗口 1280×720、进程存活且干净退出、沙盒 user 目录可写、

## 四、发现的阻断问题与修正（均已测试）

### 4.1 A13e2 出拳位移断言抖动（flaky，会随机红）

- 现象：同代码两次复跑分别 0.186 / 0.201 / 0.224，阈值 0.19 骑在抖动区间上；
- 修复：阈值 0.19 → **0.18**（低于观测下限 0.186），注释写明实测范围与理由；
  仍能有效区分"有位移"与"没动/反向（≈0）"；
- 复跑：闭环 **90/90**、演示隔离验证 OK、真实用户目录逐文件 sha256 一致。

### 4.2 开发包文件数虚报 120 → 实为 114 个唯一文件

- 根因：打包脚本"导入产物"收集阶段未去重，7 个 `.godot/imported/` 产物
  （battle sample、hero-014 ctex、tiger scn×2、wusong scn、wusong 肖像 ctex×2）各被重复计入 1 次；
  PM 逐项哈希校验能全过（每行都对应真实文件），但"共 120 个文件"与 SUMS 行数口径虚高；
- 修复：`copy_one` 按相对路径去重 + 新增自检（清单/SUMS 不得有重复路径）；
  清单标题改为「共 N 个文件，路径唯一、与 SHA256SUMS 逐行对应」；
- 复验：重打包后 SUMS **114 行 = 114 唯一路径，0 重复**，解压 `shasum -a 256 -c` 全 OK；
  试玩包解压后 headless `--auto-full` DONE、退出码 0（仅作包完整性自检，不代替真实交互）。
