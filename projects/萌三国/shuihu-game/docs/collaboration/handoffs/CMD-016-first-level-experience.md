## 二、虎的败退/倒地（当前虎无 death）

### 2.1 新资产版本：r12（r11 原样保留）

| 项 | 内容 |
|---|---|
| 新脚本 | `tools/motion/build_tiger_r12.py`（**复用 r11 的建模/绑骨/K 帧代码**，只多一条动作） |
| 产物 | `assets/releases/ART-002/r12/models/tiger.glb`、`source/tiger.blend`、`tiger_manifest.json` |
| 动作 | r11 的 4 条（idle/walk/pounce/hit）**+ 新增 `defeat`（45 帧）** |
| r11 | `assets/releases/ART-002/r11/` **一字未动**（A16b 断言 glb 与 blend 都还在） |

`defeat` 三段：**惊退（后仰压低头）→ 屈腿跪伏 → 趴伏静止（只剩轻微呼吸）**。

> 关键坑：r11 的贴地修正只保证「最低的爪底在 z=0」，光折腿**身体不会降下去**。
> 所以给 r11 的 `make_clip` 加了一个**向后兼容**的可选参数 `root_drop_fn`
> （默认 `None` ⇒ r11 行为与产物完全不变），r12 的 defeat 用它把身子压到 0.16。

### 2.2 Godot 侧演出（非血腥）

```
胜利 → 播 defeat（45 帧）→ 脚下扬尘（6 团灰褐小球，无血）
     → 整只虎的材质**复制一份**并开透明 → 淡出 + 退后 0.6 → 消散
```

- **无血、无伤口、无尸体**：虎是野兽，败退离场；台词改成
  「猛虎低吼一声，伏在地上喘气，慢慢退进林子里。」
- 材质必须**复制**再改：直接改原资源会连带影响下一战的虎和虎影
  （A16e 断言淡出材质副本都开了 `TRANSPARENCY_ALPHA`）。
