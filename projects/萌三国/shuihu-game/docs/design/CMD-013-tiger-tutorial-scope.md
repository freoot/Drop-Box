## 二、闭环范围（五步，只做这一条）

```
① 教学战：玩家控制武松 vs 虎（固定站位回合制）
      ↓ 胜利（必得，不随机）
② 招募：短对话 + 武松入队
      ↓
③ 编队：把武松放进出战位
      ↓
④ 第二战：携带武松出战
      ↓
⑤ 存档：重启后仍持有武松与编队
```

### 战斗规则（固定站位回合制，不走格子）

| 项 | 规则 |
|---|---|
| 站位 | 我方左、敌方右，固定不动，无格子、无移动 |
| 回合 | 玩家行动 → 敌方行动 → 玩家行动，循环 |
| 操作 | 点选目标（敌人）+ 点选技能（普攻 / 虎影重击） |
| 普攻 | 单体伤害，**+25 怒气** |
| 虎影重击 | 单体高伤，**消耗 50 怒气**，怒气不足时按钮禁用 |
| 虎影表现 | 武松出拳 → 猛虎虚影从武松身前扑向目标 → 虚影消散（**象征威势，不是跟随宠物**） |
| 防重入 | 行动结算中所有按钮禁用，连点无效 |
| 胜负 | 敌方 HP 归零 → 胜利；我方 HP 归零 → 失败，可重试 |

## 三、验收标准（逐条可测）

| # | 验收项 | 判定方式 |
|---|---|---|
| A1 | 回合切换 | 玩家行动结束后轮到敌方，敌方行动结束后回到玩家；日志与状态字段可查 |
| A2 | 怒气消耗 | 普攻 +25；虎影重击消耗 50；不足 50 时按钮 disabled |
| A3 | 重复点击防重入 | 行动结算中连点 5 次，只结算 1 次（伤害不叠加） |
| A4 | 胜败与重试 | 敌方归零 → 胜利；我方归零 → 失败；点「重试」回到初始状态 |
| A5 | 武松只奖励一次 | 第二次通关不再重复发放；持有数量恒为 1 |
| A6 | 编队与重启后持有 | 编队保存后重启场景/进程，武松仍在队伍中 |
| A7 | 第二战使用武松 | 第二战出战角色是武松（不是默认角色），可正常攻击 |
| A8 | 测试隔离存档 | 测试写进程唯一路径 `user://test_save_<pid>.json`，**不读写用户存档** `user://save.json` |
| A9 | 启动入口 | 双击 `play-tiger-tutorial.command` 可直接进入教学战 |
| A10 | 存档安全（CMD-014 追加） | 正式存档 `user://save.json` 受保护：**任何参数都不会删除或清空它**。`--reset-save` 对正式存档被拒绝并提示改用 `--scratch-save`；从头试玩走独立临时存档 `user://scratch_save.json`；测试走唯一隔离路径。reset / 演示 / 失败重试三个场景后，用户存档的 **sha256 与字节数完全一致** |
