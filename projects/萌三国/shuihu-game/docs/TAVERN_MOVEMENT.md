# 酒肆场景与招募 · 2026-10-15

## 本轮实现

- 酒馆从已拥有且配置了步行关节的好汉中展示三位，优先林冲、花荣、李逵。画面容器扩大至场景宽度的 36%，修正动作条上方留白导致人物过矮的问题。
- 动作使用原立绘分区 + Canvas 程序关节变形（codeart2d fallback），不是新生成的视频或完整骨骼资产。左右脚交替经历支撑、抬脚、经过和落地，停止后恢复完整待机立绘。步幅按显示比例与行走距离关联。仍使用正面/镜像朝向，未制作背面、多方向动作；长袍人物的关节表现有限。
- 现有胖掌柜素材经过 host_image 编辑后接入，CSS 轮廓裁切处理残余边缘光晕。柜台前景覆盖人物下半身，上半身和柜台招牌可点击。
- 招募使用场景弹层、三种邀约入口、角色登场动画和十连逐张展示；原概率、资源消耗、定向招募与存档逻辑保留。概率在“寻访规则与概率”展开查看。部分角色仍缺专属立绘，沿用原型示意造型。

## 路线与生命周期

人物沿桌椅间标定的通道选择相邻节点，随机停留 0.8–3.6 秒，接近其他人时退让。招募弹窗打开、页面隐藏时停止推进；离开酒馆取消动画循环；系统减少动态效果时仅显示站姿。坐标绑定 tavern-q.jpg，更换背景需重标。

## 验证

仓库根目录运行 `node --test shuihu-game/tests/*.test.mjs`。涵盖路径、步态支撑与抬脚、绘制分区、资源文件、掌柜入口、免费招募、十连暗金保底、资源不足、确认结果不再次扣费及存档。浏览器已实际验证点击掌柜、免费荐举、结果入册；不是对全部 108 将动画质量的验收。
