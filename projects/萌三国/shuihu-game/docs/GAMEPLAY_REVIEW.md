# 玩法复盘与调整顺序

## 本轮已经实施

- 征战从网页卡片列表改为六地点 2.5D 山河地图。地点、路线、驻守者、剧情摘要、普通/精英入口与解锁进度集中在同一画面。
- 每场主线增加短剧情开场，明确改编年代、地点、人物关系和战斗目标。剧情可自动播放、逐句继续、跳过或返回。
- 军令改为进入布阵时扣除。玩家查看故事或返回地图不会被重复收费。
- 林冲、花荣、吴用建立统一角色主资产，之后动作和新立绘都可使用同一人物高度、画布与脚底锚点。
- 建立 Godot 4.7.2 Compatibility 项目入口；山河地图与六个地点已在原生场景中通过无界面加载测试。

## 当前最需要继续改的玩法

1. **手动模式需要明确的战术收益**：加入敌方下一回合的目标格预警、可打断蓄力、掩体和危险区。自动模式负责日常通关，手动模式依靠信息与决策取得优势，不设置隐藏伤害加成。
2. **技能需要“范围即规则”**：目前 108 将都有独立招式名称，但 97 位仍复用职业效果组。下一步为每位好汉建立实际格形，包括单体、十字五格、周围八格、2×3 六格、直线、扇形和全场，并让预览、结算、特效共用同一个格子计算函数。
3. **技能需要二次确认**：点击名将技后先显示命中格和预计目标，再由玩家确认施放。这样可避免误触，也让“呼风唤雨、雷霆一击”等大范围技能更有策略感。
4. **Boss 要让站位改变结果**：高俅显示督战落点；史文恭点名后给一回合撤离；祝家庄阵旗提供可见连线；方腊半血号令提供蓄力提示。玩家应能用走位、控制或击破关键单位来应对。
5. **地图加入任务差异**：主线不应只做全灭。后续加入守渡口、护送粮车、拆旗、抢占箭台和救援村民，让同一套战棋有不同胜利条件。

## 数值原则

- 手动与自动使用同一伤害公式和同一敌方规则。
- 大范围技能降低单格倍率，控制技能降低伤害或增加冷却成本，避免“范围越大越强”。
- 战士靠移动和贴身压制，射手靠直线与远程覆盖，谋士靠区域、状态和救援；职业克制只提供 35% 优势，不替代站位判断。
- 新手关只展示一种新机制；精英关组合两种机制；Boss 关允许预读和反制，不使用不可见的随机秒杀。

## 资产和引擎边界

网页版继续承担完整试玩和快速验证。Godot 先迁移地图、角色主资产和战棋逻辑，不同时重写全部养成界面。人物动作遵循“一位角色一张批准主资产，再按动作制作片段”；现有四姿态图集保留为样板，不再作为后续人物动画的标准生产方式。
