# 去 AI 味前后对照（mock SOP）

两段对照：
- A. **真实流水线产物**的前后差异（`SOP-*.md` → `SOP-*.deai.md`）
- B. **重度 AI 味文本**的检测与处理，用来说明规则模式能做什么、不能做什么

规则来源：`skills/humanizer`（blader，MIT）+ `skills/no-ai-slop`（petergyang，MIT），
中文映射写在 `tools/deai.py` 的 `PATTERNS` 与 `BUZZWORDS`。

## A. 真实 SOP 的前后对比

### A1. 一句话摘要

```
改前：不写爆文、不投流，靠垂直小号 + 流量主广告。三个月做到月入 4200 元。附每日动作清单。
改后：不写爆文、不投流。靠垂直小号 + 流量主广告。三个月做到月入 4200 元。附每日动作清单。
```
改动：把 26 字的并列句拆成两句。数字、平台名一个没动。

### A2. Day 5 动作

```
改前：开通流量主后，把广告位放在文末，不打断阅读。单篇阅读 1200 左右时。一天三条的广告收益大约 45 元。
改后：开通流量主后，把广告位放在文末。不打断阅读。单篇阅读 1200 左右时。一天三条的广告收益大约 45 元。
```
改动：一句说了三件事，拆成三句。每句只留一个动作或一个数字。

### A3. 证据

```
改前：先说结论：这个号从注册到月入 4200 元，用了 92 天，全程没有投过一分钱推广。
改后：先说结论：这个号从注册到月入 4200 元，用了 92 天。全程没有投过一分钱推广。
```

### A4. 改动统计

```
acc_demo_001-333e19cd.project.json：11 处改动
SOP-公众号流量主第-3-个月.md：9 处改动 → SOP-公众号流量主第-3-个月.deai.md
```

为什么差异不大：SOP 的文字来自原文提取，本来就带具体数字和动作，AI 味不重。
deai 只做「最小有效改动」，不把已经通顺的句子再改一遍（这条来自 no-ai-slop 的编辑原则）。

## B. 重度 AI 味文本：检测准，改写会坏

### B1. 输入（典型 LLM 腔）

> 本项目致力于通过深度融合内容运营与私域流量，打造一站式副业变现闭环，全面提升个人 IP
> 的商业价值。值得一提的是，该模式不仅是内容分发，更是用户心智的系统性占领。首先，需要
> 明确垂直赛道的选择；其次，持续输出高质量内容；最后，通过社群运营实现转化。经过三个月
> 的持续发力，账号实现了显著提升，未来可期。

### B2. 检测结果（11 处，只报不改）

| 模式 | 命中原句 | 建议 |
|---|---|---|
| 套话 | 深度融合 | 直接删 |
| 套话 | 一站式 | 直接删 |
| 套话 | 闭环 | 直接删 |
| 套话 | 打造 | 直接删 |
| 套话 | 全面提升 | 直接删 |
| 套话 | 持续发力 | 直接删 |
| 元评论 | 值得一提的是 | 删掉，直接说事 |
| 假深刻 | 不仅是内容分发，更是 | 说清楚具体是什么 |
| 空洞提升 | 全面提升 / 显著提升 | 换成具体数字 |
| 空洞收尾 | 未来可期 | 删掉，用具体下一步代替 |

检测部分是准的：11 处全部命中，没有误报。

### B3. 直接删词的结果：病句

```
本项目致力于通过内容运营与私域流量，副业变现，个人 IP 的商业价值。
该模式用户心智的系统性占领。
```

删词删掉了谓语，句子散架。**这是规则模式的硬限制：只能「减」，不能「重写」。**

### B4. 现在的处理：回退 + 标记

`clean_text_safe()` 检测到删词后句子不完整（句首标点、连续标点、「通过 X，Y。」缺谓语），
就**回退原文**，并在报告里标记 `需重写`：

```
需重写：删词后句子不完整，已保留原文
```

宁可保留一句 AI 腔，也不往 SOP 里塞病句。

## C. 结论与建议

| 场景 | 用什么 | 效果 |
|---|---|---|
| SOP 正文（源头是原文提取，AI 味轻） | 规则模式（默认） | 拆长句、删少量套话，安全 |
| 项目摘要由 LLM 生成、AI 味重 | **LLM 模式**（配 `LLM_API_KEY`）+ `prompts/deai.md` | 能整句重写，不是只删词 |
| 没有 LLM、又要处理重 AI 味文本 | 人工按 `prompts/deai.md` 改 | 规则模式只负责标出问题 |

规则模式的价值不在「改得多」，而在**可复现、可审计**：每次改了哪几处、命中哪些模式，
都写在 `data/deai-report.json` 里。
