# SOP · 公众号流量主第 3 个月

> 不写爆文、不投流，靠垂直小号 + 流量主广告。三个月做到月入 4200 元。附每日动作清单。
>
> 等级 **S（45/50）** ｜ 来源：副业研究所（示例） ｜ 生成：2026-10-29T11:20:37+08:00

## 一、项目是什么

不写爆文、不投流，靠垂直小号 + 流量主广告。三个月做到月入 4200 元。附每日动作清单。

## 二、第一周可复制动作

- [ ] **Day 1**：选一个足够窄的领域。我选的是「县城事业单位报考信息」，全国有需求但没人系统整理。窄领域的好处是竞争小、差异化明显，用户一看标题就知道是不是给自己看的。
- [ ] **Day 2**：每天固定发 3 条：1 条政策原文摘编、1 条岗位汇总、1 条报考答疑。全部用模板。单条制作时间控制在 20 分钟内。
- [ ] **Day 3**：标题只写「地区 + 岗位数 + 截止时间」。不做标题党。实测这类标题的打开率稳定在 8% 左右。
- [ ] **Day 4**：第 1 个月目标不是赚钱。是攒够 500 粉丝开通流量主。我在本地备考群里做了 3 次免费资料分享。导进来 620 个粉丝。
- [ ] **Day 5**：开通流量主后，把广告位放在文末，不打断阅读。单篇阅读 1200 左右时。一天三条的广告收益大约 45 元。

## 三、证据

- 先说结论：这个号从注册到月入 4200 元，用了 92 天，全程没有投过一分钱推广。
- 实测这类标题的打开率稳定在 8% 左右。
- 单篇阅读 1200 左右时，一天三条的广告收益大约 45 元。
- 第 1 个月：粉丝 620，收益 0 元。
- 第 2 个月：粉丝 2100，收益 1860 元。
- 第 3 个月：粉丝 4800，收益 4200 元。
