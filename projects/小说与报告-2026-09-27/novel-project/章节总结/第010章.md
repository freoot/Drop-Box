# 第010章 剑里的火

- 因果：剑焦印促啾啾追问，顾长渊坦承只记得旧火海与胸口被火穿过，承认先前隐瞒；两人建立“想起就说”的新约，谢清和带来昨夜假掌门领钥记录。
- 场景链：廊下对质旧剑印 → 顾说有限记忆与隐瞒理由 → 啾啾指出隐瞒并未阻止她入墓 → 七道刻痕提示七人旧承诺但内容不全 → 钥匙簿出现无命纹签名。
- 新事实：顾长渊确记得抱婴离火海、六人去挡门、自己被火穿胸；死亡仍为推断，不能写成已证。他早不知墓里有第二婴儿。剑鞘有七道旧痕。
- 人物关系：啾啾对顾的沉默提出要求，顾承诺后续坦白；信任经历质疑而未断。
- 伏笔：P003/P008加强；P005昨夜伪签领旧碑库钥匙。
- 下一章接口：钥匙可能在玄苍或其代理人手里，众人须在不施术条件下进入旧碑库。
- 两轮自检：顾只说自身可记部分，没有替六人确认死亡；隐瞒有动机且受啾啾反驳；对话中剑痕和钥匙簿改变下一步。
