# 第005章 不许点火

- 因果：玄苍夺骨片时，啾啾以骨片引黑兽阻他，师兄们不用灵力推倒锁天阵石基，趁阻隔带伤者逃至药庐。
- 场景链：玄苍进逼 → 骨片诱兽与玄苍争抢 → 众人用铁钉、铜扣、玄铁锤压落石基 → 发现尚有脉搏的执法弟子，选择救他而拖慢撤离 → 药庐手工救治。
- 不可逆变化：唐烈胸伤明确为断肋，不能施术速愈；新增存活执法弟子陈砚，知道宗门命册可验证三日之限。
- 伏笔：P004玄苍仍能追，身体破裂落灰；P007红线受婴儿哭声牵动；P009转向命册验证。
- 下一章接口：众人在药庐，玄苍敲石声已停但去向不明；必须验命册，唐烈需要治疗。
- 两轮自检：黑兽追骨片源于前章行为，不作为听话宠物；压柱造成时间窗口而非轻易杀玄苍；删去均匀情绪标签，保留行动后果。
