# 第019章 第八盏灯

- 因果：啾啾知用自己的名字封门会被门持续索取记忆且不能离青云，仍自愿按门印报出姓名；红线连骨片与七碑，七人各自再认名，金线归本人，黑灯熄，玄苍失借火而崩；苏名成为第八盏无火门闩。
- 场景链：命影告知代价 → 啾啾托婴、自己按内印报姓名 → 红线接碑，七人各自报姓名 → 命线回归、借火脱玄苍，门合 → 命影消散并托付婴儿名字；留山限制待实测。
- 新事实：七金线归七人后可摆脱黑灯与婴儿；苏啾啾的“名字”可作无火门闩，离山则闩松，门还会索其记忆。玄苍尸身失火崩散，活人部分火回返，已死者未被无故复活。
- 人物：啾啾自愿承担命影所述的留山约束，尚待在山门实测；命影完成护婴守门目标后散去；婴儿仍无自选名字。
- 伏笔：P004/P006主体回收；P007能力与代价回收但记忆损失尚待长期验证；P012单人牺牲方案被替代。
- 下一章接口：门闭、三夜危机可望止住，啾啾必须验证宗门命册与留山限制，并与婴儿商议名字。
- 两轮自检：新法基于归名、七碑、红线和骨片先前实测；留山代价未在墓室一步就写成证实；死亡后果不被全员复活抹平。
