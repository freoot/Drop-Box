# 第011章 面具里面

- 因果：众人查旧碑库，遇到被控的守碑人陶姑带钥来锁门兼夺婴，合力不用灵术夺钥开门；陶姑受面具压制只划出“生”，啾啾见地下弱命灯。
- 场景链：旧碑库门与失钥状况 → 缺指陶姑出现、黑线索婴 → 陈砚与林霜争门、谢清和开锁 → 陶姑冒痛划“生”受面具反噬 → 啾啾见地下活人命灯。
- 新事实：陶姑为旧守碑人，现面具化；面具铜边伤及脸，不能粗暴揭除。地下确有一盏活人命灯，身份待证。
- 人物：林霜救陶姑但仍有被黑线牵制风险；陶姑选择以残指警告，非纯傀儡。
- 伏笔：P005掌门生存可能增强；P006主灯区域即将验证；新增P011陶姑能否归名解除面具。
- 下一章接口：旧碑库门已开，众人须下去找灯主与主灯；陶姑由守阁弟子看守，仍受控。
- 两轮自检：陶姑第一强出场有职司与缺指动作；“生”不被误写成掌门身份证据；林霜不轻易揭致命面具。
