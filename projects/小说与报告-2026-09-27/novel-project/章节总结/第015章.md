# 第015章 不要替我选

- 因果：掌门提出将有完整命火的墓中婴儿放回王座代七而死，啾啾拒绝；她与顾在七名碑上试出本人触名可短暂松线，改寻七人自愿归名再解门闩之法。
- 场景链：掌门明确一命代七是婴儿牺牲 → 啾啾拒绝代她同意 → 顾本人触碑黑线短松形成试验证据 → 掌门提出旧火松后新门闩难题 → 啾啾回药庐征询七人，陆小满提醒她也不可默吞代价。
- 新事实：一命代七方案会令婴儿在第三夜后死；当前七名碑可响应本人无灵力触名，但效果短暂。即使解七线，门仍需新闩。
- 人物：啾啾拒绝用他人命作算术；顾愿亲试；陆小满由莽撞救人转为提醒啾啾保护自己；唐烈伤未愈。
- 伏笔：P012方案性质回收但未采用；P006七人认名新法待验证；P007红线是否可作新闩仍未知。
- 下一章接口：第二夜将临，六灯仍抽；七师兄尚未逐个同意试验，门闩方案缺代价评估。
- 两轮自检：啾啾拒绝牺牲婴儿，不能替师兄作决定；新办法有首灯归名与本人触碑两处实证但仍未保证成功；伤势和时间压力持续。
