# 第013章 掌门没有死

- 因果：掌门在旧碑库承认十年前七少年天门前确死，白袍女子赠七命使其复生；掌门未经七人同意用其命灯镇门，如今玄苍死躯被黑线驱动并伪印急召。掌门提出“一命代七”。
- 场景链：顾长渊旧忆与掌门口述对上 → 啾啾区分赠命与借命 → 顾追问七人同意，掌门承认没有 → 谢追问玄苍与伪印 → 灯压碑库，掌门递出单人替代方案。
- 新事实：十年前七人曾死又由女子七火真救回；当年顾抱出的婴儿是现在苏啾啾；七灯为掌门后来所设，未经七人同意；玄苍十年前封门时死，现被黑线操尸；伪印出自旧模。
- 人物：顾长渊直指掌门责任；啾啾不把赠命等同永久索命；掌门仍守钉且有一命代七方案，未验证可行。
- 伏笔：P003/P008旧死事得到掌门口述与旧碑证实；P004/P005较大回收；P002七命归属争议仍在；新增P012“一命代七”的人选和代价。
- 下一章接口：啾啾需查“一命代七”到底要谁的命，同时查第二婴儿与女帝命影身份。
- 两轮自检：事实由掌门口述与碑、顾记忆互证，但女子身份仍不强行定论；掌门承认未征同意而非被一句“全宗”洗白；没有让他离开镇门钉。
